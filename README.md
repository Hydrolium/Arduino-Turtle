# 🐢 아두이노 거북이 로봇 (Arduino Turtle Robot)

아두이노 우노(Uno)를 기반으로 다양한 모듈을 결합하여 제작한 거북이 로봇 프로젝트의 전체 코드입니다. `delay()`를 사용하지 않는 넌블로킹(Non-blocking) 멀티태스킹 구조와 각 모듈을 `Initializable`과 `Updatable`을 상속받는 객체로 정의하는 객체 지향 프로그래밍을 적용하여 확장성과 안정성을 극대화했습니다.

---

## ✨ 주요 기능 (Features)

1. **근거리 위험 감지 및 방어**: 초음파 센서로 전방 20cm 이내에 장애물이 감지되면 목을 신속하게 집어넣어 방어 자세를 취합니다. 다시 안전해지면 목을 뺍니다.
2. **RFID 상호작용**: 목을 넣고 있을 때 특정 RFID 태그를 인식시키면 태그 종류(ID)에 따라 빠르게 목을 빼거나, 일반 속도로 빼거나, 화를 내는(눈 LED 깜빡임) 반응을 보입니다.
3. **조이스틱 교감**: 조이스틱을 조작하면 거북이가 좋아하는 반응으로 눈(LED)을 반짝이며 양 앞다리로 헤엄치는 모션을 취합니다.
4. **뒤집힘 감지**: 기울기 센서를 통해 거북이가 뒤집히는 것을 감지하면, 다시 바로잡아달라는 듯이 양 앞다리를 허우적거리는(Struggling) 모션을 취합니다.
5. **일광욕 모드**: 조도 센서로 강한 빛을 감지하면 무드등 효과와 함께 양 앞다리를 쭉 펴고 일광욕(Sunbathe)을 즐깁니다. 반대로 너무 어두워지면 무드등이 잠시 켜집니다.
6. **IR 리모컨 원격 제어**: 적외선 수신기와 리모컨을 통해 각 모드(헤엄치기, 목 넣기/빼기, 무드등 ON/OFF, 눈 ON/OFF)를 강제로 실행할 수 있습니다.

## 🛠 하드웨어 구성 (Hardware Components)

* **컨트롤러**: 아두이노 우노 (Arduino Uno), 브레드보드
* **구동 모듈**: 
  * 서보모터 x 3 (오른쪽 앞다리와 왼쪽 앞다리 서보, 목 제어용 360도 서보)
  * LED x 2 (왼쪽 눈, 오른쪽 눈)
  * 릴레이 모듈 (무드등 제어용)
* **센서 모듈**:
  * 초음파 센서 (HC-SR04) - 거리 측정
  * RFID-RC522 모듈 - 태그 인식
  * 조이스틱 모듈 - 아날로그 입력 및 스위치
  * 기울기 센서 - 뒤집힘 감지
  * 조도 센서 (포토 레지스터) - 밝기 감지
  * IR 적외선 수신기 및 리모컨
* **전원**: 9V 배터리, AA 배터리 4구 (배터리 2구 x 2) 및 저항 소자류 (10K옴, 220옴)

## 💻 소프트웨어 아키텍처 (Software Architecture)

본 프로젝트는 아두이노 환경에서 흔히 발생하는 `delay()`로 인한 프로그램 멈춤 현상을 완전히 해결하기 위해 다음과 같은 고급 설계 패턴을 적용했습니다.

* **인터페이스 기반 설계 (`Component.h`)**: 모든 센서와 구동 모듈은 `Initializable`(초기화)과 `Updatable`(매 루프 상태 업데이트) 인터페이스를 상속받아 표준화된 인터페이스로 관리됩니다.
* **넌블로킹 멀티태스킹 (`main.ino`)**: 메인 `loop()`는 각 컴포넌트 배열을 순회하며 `millis()` 기반의 `update()` 함수만 실행하므로, 모터 구동과 센서 감지가 완벽하게 동시 처리됩니다.
* **상태 관리 및 동작 예약 시스템 (`TurtleMotion.h`)**: `MotionManager` 템플릿 클래스를 도입하여 현재 로봇의 행동 상태를 관리합니다. 함수 포인터를 사용해 행동을 동적으로 연결하며, 현재 동작 중일 때 다음 동작을 예약(`book()`)하는 로직이 구현되어 있습니다.
* **부드러운 이징(Easing) 모션**: 서보모터 제어 시 수학적 보간 공식($3x^2 - 2x^3$) 기반의 가감속 기법(`easing`)을 적용하여 하드웨어 충격을 줄이고 생명체 같은 자연스러운 모션을 구현했습니다.
